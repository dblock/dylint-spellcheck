# Bundled English dictionary

Unmodified SCOWL-derived en_US Hunspell dictionary, version 2020.12.07 (size 60), copied from [rubocop-spellcheck v0.2.0](https://github.com/dblock/rubocop-spellcheck/tree/v0.2.0/data/en). [LICENSE](LICENSE) contains the upstream copyright, redistribution terms, and provenance. Both dictionary files are embedded in the lint library; using the defaults never downloads resources.
